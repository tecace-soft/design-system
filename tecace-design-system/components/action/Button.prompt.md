# Button
Primary tap/click action. Use for form submits, confirmations, and calls-to-action.

```jsx
<Button label="지원하기" variant="solid" color="primary" size="lg" onClick={apply} />
<Button label="취소" variant="outlined" color="assistive" />
<Button label="저장 중" loading />
```

Variants: `variant` solid|outlined · `color` primary|assistive · `size` sm|md|lg · `iconOnly`, `disable`, `loading`, `leadingIcon`, `trailingIcon`.
